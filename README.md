## 🔬 Обзор проекта

Проект представляет собой научно-исследовательскую работу в области **Data Science** и **Digital Health**. Основная цель — создание модели, способной на ранних этапах выявлять пациентов с высоким риском летального исхода, анализируя сложные взаимосвязи между хроническими заболеваниями и течением вирусной инфекции.

Система автоматизирует процесс скоринга здоровья, помогая медицинскому персоналу в принятии решений при сортировке (triage) пациентов.

## 🛠 Конвейер обработки данных (Data Pipeline)

Особое внимание в проекте уделено подготовке данных (ETL), так как медицинские датасеты часто содержат шум и пропуски:

### 1. Очистка данных (Cleaning)
- **Устранение шума:** Технические значения-заглушки (`97`, `98`, `99`), используемые в исходных данных вместо пропусков, автоматически заменяются на `NaN`.
- **Feature Selection:** Исключены признаки с критическим дефицитом информации (более 50% пропущенных значений), такие как `PREGNANT`, `ICU` и `INTUBED`.
- **Target Engineering:** Целевая переменная формируется путем анализа поля `DATE_DIED`. Дата смерти трансформируется в бинарный флаг: `1` (летальный исход), `0` (выздоровление).

### 2. Заполнение пропусков (Imputation)
- Признак `AGE` заполняется медианным значением для исключения влияния аномальных выбросов.
- Признак `PNEUMONIA` восстанавливается на основе модального значения выборки.

### 3. Нормализация (Scaling)
- Применяется **StandardScaler** для центрирования данных. Это критически важный этап для нейронных сетей, обеспечивающий стабильную работу градиентного спуска при обучении модели.

---

## 🧠 Архитектура нейронной сети

Для классификации используется **MLPClassifier** (Multi-layer Perceptron):

*   **Топология:** Многослойная структура с двумя скрытыми слоями (50 и 30 нейронов соответственно).
*   **Обучение:** 500 итераций для обеспечения глубокой сходимости весов.
*   **Валидация:** Используется разделение выборки на обучающую и тестовую (train/test split), а также расчет кросс-валидации для подтверждения стабильности модели.

---

## 📊 Оценка качества

Система предоставляет комплексный отчет о результатах предсказания:
1.  **Accuracy Score:** Общая точность классификации.
2.  **Confusion Matrix:** Визуализация ошибок первого и второго рода (ложноположительные и ложноотрицательные срабатывания).
3.  **Classification Report:** Детальный анализ точности (precision), полноты (recall) и F1-меры для каждого класса.
